# Separate portfolio editions

The original homepage and `work/` cases remain unchanged. The Clay research edition is `clay-ux-researcher/index.html` in this folder. `index.html` lists the general portfolio and available editions without redirecting the original homepage.

Edit role copy and documented chronology in `../variants/clay-ux-researcher.json`; shared role structure in `../templates/role-home.html`; and edition styling/choreography in `clay.css` and `clay.js`. Run `python3 ../scripts/build_versions.py` from this directory, or `python3 scripts/build_versions.py` from the repository root.

`clay-case.js` is generated by `scripts/build_clay_motion.py` from the preserved root `case.js`. It replaces crossfade overlap with a short surface cue with static reading content, retains the moving tab rail, sizes galleries to their selected content, and preserves screenshot inspection, zoom and focus behavior. Do not hand-edit the generated file.

Run `python3 scripts/check_versions.py` and `node concepts/state.test.cjs` from the repository root. Review every edition affected by shared asset or baseline changes before publishing. Case overrides intentionally fail if an expected source passage has changed.

See `BRAND-NOTES.md` for the inferred visual direction and its limits.
