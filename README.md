# Ricky Sanderson — Product & UX designer

A compact, static portfolio built with plain HTML, CSS and JavaScript for GitHub Pages. It has no build step, server-side code, external fonts, paid assets or third-party JavaScript dependencies.

## Preview locally

From this directory, run:

```sh
python3 -m http.server 8000
```

Then open `http://127.0.0.1:8000/`. The project pages are ordinary relative links and work when served from the repository root.

## Deploy with GitHub Pages

1. Put the contents of this directory at the root of the new portfolio repository.
2. In the repository’s **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
3. Wait for GitHub Pages to finish building before sharing the published URL.

No repository or public URL is configured by these files. `ASSET_SOURCES.md` records the origin and use limits for each portfolio asset. The assets are not released as a general stock or open-license collection; retain their source attribution and permissions if moving or reusing them.
